# Epic: Coursework Management

## User Story
**As a** student
**I want** to complete the Math Assignment: Module 1 Discussion
**So that** I can submit it by Wednesday and receive credit.

## Acceptance Criteria
- [ ] Assignment is identified as "Math Assignment: Module 1 Discussion".
- [ ] Assignment due date is set to Wednesday.
- [ ] System sends a reminder before the due date.
- [ ] Submission successfully registers in the system.

## Technical Requirements
- Database must support due date fields for assignments.
- Frontend should display a countdown or clear indication of the Wednesday deadline.
- Notification service should trigger a reminder.
